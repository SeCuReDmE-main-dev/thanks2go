# Privacy notice

Thanks2Go does not create user accounts, scan pages in the background, maintain a social graph, rank creators, or operate a payment-history database. The extension reads only the explicit Thanks2Go link/meta declaration and the visible page origin after a user clicks its action.

PayPal processes its own checkout data. Thanks2Go discards payer name and email and exposes only a one-way hash of PayPal's payer identifier in a successful receipt. Solana devnet addresses and transactions are public on the devnet ledger; the interface truncates addresses but cannot make blockchain data private.

Operational logs must exclude request bodies, credentials, payment links, payer PII, and wallet secrets.
