## Narrow expiry-recovery addendum

Root review found that the page still classified PayPal expiration by message text, did not clear expired capture state, and could leave `?paypal=return&token=...` displaying an inactive capture control. `apps/web/src/payment-recovery.ts` now centralizes recovery on the public `ApiError.code === "MANDATE_EXPIRED"` contract. PayPal start/capture remove only the expired stored mandate and PayPal return parameters, then deactivate the capture view; Solana clears only the expired stage and wallet choices. All three paths require a fresh visible human action. Non-expiration errors leave stored/query/stage state intact so the existing idempotent resume remains available. `tests/payment-recovery.test.ts` covers PayPal cleanup, Solana deactivation, and non-expiration preservation without a DOM framework. `npm run typecheck`, the four-file targeted suite (21 tests), and the production web build passed.
